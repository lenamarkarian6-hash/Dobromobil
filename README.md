# Добромобиль

Сайт помощи приютам для животных. Django + HTML/CSS/JS.

## Вкладки сайта

Главная · О нас (вместе с контактами) · Регистрация (регистрация и вход в личный кабинет) ·
Карта приютов · Правила · Отзывы (вместе с отчётами) · Вопросы · Пожертвования

## Роли и личные кабинеты

| Роль        | Что есть в кабинете |
|-------------|---------------------|
| Волонтёр    | запись на рейсы и отмена, история рейсов, учёт часов |
| Амбассадор  | личная ссылка-приглашение, список приглашённых, запись на рейсы |
| Организатор | статус заявки приюта, потребности приюта, создание рейсов, отметка участников и часов |
| Фандрайзер  | создание сборов (после модерации видны на вкладке «Пожертвования»), прогресс, поступления |

Администратор сайта (createsuperuser) работает в `/admin/`: одобряет заявки приютов
(действие «Одобрить и добавить приют на карту»), сборы, отзывы, подтверждает оплату пожертвований,
заполняет отчёты.

## Запуск

    python -m venv venv

Windows:

    venv\Scripts\activate

Linux/Mac:

    source venv/bin/activate

Затем:

    pip install -r requirements.txt
    python manage.py migrate
    python manage.py create_roles
    python manage.py createsuperuser
    python manage.py runserver

Откройте http://127.0.0.1:8000/

Тесты: `python manage.py test core`

## Реквизиты

Реквизиты организации (ИНН, ОГРН, банк, счёт, телефон для СБП) задаются в одном месте —
`ORGANIZATION` в `dobromobil/settings.py`. Они выводятся в подвале и на странице оплаты пожертвования.
